# Анализ денежных переводов и отправленных платежей

# Описание проекта

Данный проект направлен на реализацию SQL-скриптов для анализа и отчетности по денежным переводам, осуществленным банками Российской Федерации. Проект включает в себя три задания, каждое из которых решает специфическую задачу, связанную с обработкой данных о денежных переводах.

## Задания:
1. Подсчет оборота денежных переводов.  
 **Цель:** Получить статистику, показывающую эффективность проведенной в мае стимулирующей кампании.   
**Описание:** Реализовал SQL-скрипт, который подсчитывает общий оборот отправленных денежных переводов за первую декаду июня. 
2. Подробный отчет о платежах
**Цель:** Предоставить менеджеру компании детальный отчет об отправленных платежах за июнь.   
**Описание:** Создать SQL-скрипт, который выводит подробную информацию об отправленных платежах за июнь. 
3. Список клиентов-отправителей
**Цель:** Провести кампанию по рассылке рекламных СМС-уведомлений клиентам системы.

**Описание: ** Разработать SQL-скрипт, который выводит список ФИО клиентов-отправителей, совершивших более двух платежей за июнь. Для каждого клиента необходимо указать количество совершенных платежей и общую сумму отправленных ими платежей.
